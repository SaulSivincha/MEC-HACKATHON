# ORBITA — Gemelo Digital Minero

Prototipo visual autocontenido de 20 segundos para explicar cómo un gemelo digital detecta una cola, evalúa alternativas y reasigna camiones entre palas.

## Construcción

- Escena 3D: React Three Fiber + Three.js.
- Estado: escenario determinista local, sin APIs ni backend.
- Narrativa: operación → congestión → análisis → reasignación → KPIs optimizados.
- Controles: pausa, continuación y repetición de la simulación.

## Ejecutar

```bash
pnpm install
pnpm dev
```

El directorio no tenía repositorio Git ni remoto configurado al inicio; por eso no fue posible ejecutar `git pull`.
